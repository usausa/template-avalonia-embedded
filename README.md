# Template project for Avalonia embedded

[Template](https://usausa.github.io/template/) project for Avalonia embedded.

## 🖥️ Screens

<img width="50%" src="./docs/dashboard.png" />

- SoC temperature, clock, voltage, and throttling
- CPU, memory, disk, network, Wi-Fi, and device status

<img width="50%" src="./docs/monitor.png" />

- Gauges for CPU, temperature, and memory with a 60-second trend

<img width="50%" src="./docs/gpio.png" />

- Function and level of each pin on the 40-pin header, paged 20 pins at a time

<img width="50%" src="./docs/input.png" />

- Pad connection status, and the press state, assignment, and last action of each key
- Recent input (press, long press, repeat)

<img width="50%" src="./docs/drive.png" />

- Speed and steering with the Build HAT

<img width="50%" src="./docs/graphics.png" />

- Animation, analog clock, shapes, a waveform drawn every frame, and fps

<img width="50%" src="./docs/typography.png" />

- Various fonts and emoji
